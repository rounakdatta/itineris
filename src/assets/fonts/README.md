Two web fonts for captions, both under the SIL Open Font License 1.1 (texts alongside):

- **Caveat** (`caveat-latin.woff2`, latin subset, weight 700) — Copyright 2014 The Caveat Project Authors.
- **Bebas Neue** (`bebasneue-latin.woff2`, latin subset) — Copyright 2010 Dharma Type.

They are bundled (hashed by Vite) rather than fetched from Google, so captions look the same offline and on every device.
